# Reading list

Things worth coming back to, with the reason I kept them.

- **The Mythical Man-Month**, Brooks — the chapter on the second-system
  effect, which describes almost every rewrite I have watched go wrong.
- **Notes on the Synthesis of Form**, Alexander — for the idea that a design
  problem is a set of misfits, and that you work by removing them rather than
  by describing the good version up front.
- **A Pattern Language** — less useful as patterns than as an argument that
  the small decisions are where a place gets its character.
