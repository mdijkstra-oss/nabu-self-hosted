# Codebook — rules

Rules that govern every code in this book. A rule that would read the same with every code name removed belongs here; a rule that names one code belongs in that code's definition.

## What a passage is

The unit is the sentence, extended to neighbouring sentences only when the shorter span cannot be judged on its own. A span that needs the sentence before it to make sense takes that sentence with it.

Never a fragment. A coded span that is not a whole sentence teaches the reader to match vocabulary rather than function, which is the failure this book exists to avoid.

## Overlap

A passage may carry more than one code and usually should. The codes here are deliberately narrow: each names one thing, so a sentence doing two things gets two codings rather than one code stretched over both.

Two codes on the same span are not a conflict. Two codes that would always appear on the same span are one code badly split, and should be reported.

## Deciding

A passage is judged with that passage and this book in hand, and nothing else. A criterion that needs to know what happened in another month, or what a man was like on the ship, silently defaults to no for every reader — such a criterion is a defect in the definition, not a hard case.

Where a passage is genuinely undecidable, leave it uncoded and highlight it with a colour and a reason. An uncoded highlight is a note to the researcher, not a failure.

## The hands

The journal is kept in rotation by the night watch, so the hand changes with every entry and the initials at the end name the writer. Six men write here and they do not write alike: one keeps figures, one barely spells, one writes to be read by the others.

None of that changes what a passage means. A code is applied to what the passage does, never to who wrote it. If a code seems to belong to one man, it is describing a habit of writing rather than a thing that happened, and it should be reported.

## The notebook

`notebook-mowbray.md` is the leader's private book and was written for nobody. The same events appear there and in the journal in different registers. It carries the same codes on the same terms — it is not a separate scheme — but a code whose rate differs sharply between the two documents is telling you something about the definition and should be reported rather than explained away.
